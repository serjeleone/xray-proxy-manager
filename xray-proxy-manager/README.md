# Xray Proxy Manager

[![Release](https://github.com/serjeleone/xray-proxy-manager/actions/workflows/build.yml/badge.svg?event=release)](https://github.com/serjeleone/xray-proxy-manager/actions/workflows/build.yml?query=event%3Arelease)
[![Добавить репозиторий в Home Assistant](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Fserjeleone%2Fxray-proxy-manager)

Xray Proxy Manager — приложение Home Assistant для работы с подписками в формате Xray JSON. Такая подписка содержит одну или несколько конфигураций Xray с outbound, правилами маршрутизации и сопутствующими параметрами. Приложение разбирает эту структуру, выделяет доступные outbound, проверяет их и формирует управляемые конфигурации для переключения прокси. Поддерживаются двухслотовая схема с сохранением уже установленных соединений и однослотовая схема с перезапуском Xray при смене outbound.

Приложение предоставляет управляемые SOCKS5-слоты и может координировать их с совместимым внешним selector. Способ передачи клиентских соединений в слоты определяется внешней системой.

## Возможности

- загрузка и периодическое обновление JSON-подписки;
- веб-интерфейс через Home Assistant Ingress;
- ручная и автоматическая проверка outbound по двум независимым URL;
- фильтрация автоматического выбора по ISO-кодам стран и ключевым словам;
- автоматический выбор разрешённого outbound с меньшей задержкой и приоритетом определенной страны;
- однослотовый или двухслотовый режим работы; двухслотовый режим `xray-a`/`xray-b` с предварительной проверкой, selector, дренированием и откатом;

## Режимы слотов

### Однослотовый

При `dual_slot_enabled: false` используется только один слот, `xray-a`. Менеджер заранее формирует и проверяет новую конфигурацию, затем останавливает текущий Xray вместе со всеми TCP/UDP-соединениями, устанавливает уже проверенную конфигурацию и запускает слот повторно.

### Двухслотовый

При `dual_slot_enabled: true` новый outbound запускается в свободном слоте и проверяется до переключения внешнего selector. После переключения новые соединения направляются в новый слот, а прежний Xray продолжает обслуживать уже установленные соединения до завершения дренирования.

Для автоматического переключения используется совместимый selector API. Для расширенной диагностики дренирования API может дополнительно предоставлять список соединений и цепочки использованных outbound.

## Сетевые интерфейсы

| Настройка | Значение по умолчанию | Назначение |
|---|---:|---|
| `Slot A SOCKS port` (`socks_tcp_a`) | `10808` | Единый TCP/UDP-порт SOCKS5-слота `xray-a`. |
| `Slot B SOCKS port` (`socks_tcp_b`) | `10809` | Единый TCP/UDP-порт SOCKS5-слота `xray-b` (в двухслотовом режиме). |

К слотам можно подключаться напрямую либо через внешний прокси, маршрутизатор или сетевой шлюз. Xray Proxy Manager управляет Xray и состоянием слотов, а правила доставки клиентского трафика определяются внешней сетевой конфигурацией.

Порт внутреннего веб-интерфейса задаётся параметром `ui_port`. Home Assistant Ingress использует автоматически выделенный свободный порт и перенаправляет запросы на `ui_port`; watchdog проверяет отдельный служебный endpoint и не зависит от выбранного порта интерфейса.

## Установка

1. Откройте **Настройки → Приложения → Магазин приложений**.
2. Добавьте репозиторий `https://github.com/serjeleone/xray-proxy-manager`.
3. Установите **Xray Proxy Manager**.
4. Укажите `subscription_url`.
5. Выберите режим `dual_slot_enabled` в настройках или кнопкой режима в веб-интерфейсе.
6. Для управляемой двухслотовой схемы настройте `selector_*`.
7. Запустите приложение и откройте веб-интерфейс.

## Пример двухслотовой конфигурации

```yaml
subscription_url: "https://example.com/subscription.json"
dual_slot_enabled: true
socks_tcp_a: 10808
socks_tcp_b: 10809
selector_control_enabled: true
selector_api_url: "http://192.168.1.1:9090"
selector_api_secret: ""
selector_tag: "xray-active"
auto_switch_excluded: "RU, Определенный_сервер"
auto_switch_preferred_country: "NL"
primary_test_url: "https://www.gstatic.com/generate_204"
secondary_test_url: "https://cp.cloudflare.com/generate_204"
ui_port: 8099
ui_hide_excluded: true
```

Совместимый selector должен содержать точные элементы `xray-a` и `xray-b` и позволять прочитать и изменить текущий выбор.

## Проверки и исключения

`primary_test_url` и `secondary_test_url` запрашиваются параллельно. Если доступны оба адреса, берется наименьшая задержка; если отвечает только один — используется его результат. Слот считается деградировавшим, когда задержка превышает `auto_check_max_latency_ms`; ошибка доступности засчитывается только при отказе обоих адресов.

В `auto_switch_excluded` можно совместить точные двухбуквенные коды стран и текстовые фрагменты. Например, `RU, Определенный_сервер` исключает страну RU и любой outbound, в имени или технических полях которого встречается фрагмент `Определенный_сервер`. Фильтр интерфейса `ui_hide_excluded` включён по умолчанию и скрывает такие outbound из списка.

`auto_switch_preferred_country` задаёт ISO-код страны с приоритетом. При выборе страны в UI уже известный подходящий outbound этой страны сразу проходит пред-switch проверку и активируется, после чего выполняется полная проверка. Если хотя бы один outbound этой страны доступен, не исключён и укладывается в `auto_check_max_latency_ms`, лучший выбирается среди них. Иначе выбор выполняется среди всех подходящих outbound.

Обновление подписки сначала выполняется напрямую, без SOCKS-слотов. Только при ошибке менеджер пробует уже запущенные слоты, начиная с активного. Новые данные применяются к списку outbound, а текущие процессы Xray продолжают работать до явного выбора конфигурации или смены режима.
